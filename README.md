# stock-charts.el

Emacs 上で動作する株式チャートブラウザと、東証全銘柄のインクリメンタル検索ツールです。

日本株・米国株・ETF の複数銘柄のチャートを、ウィンドウ幅に応じたグリッドレイアウトで一覧表示します。楽天証券の通常テクニカルチャートと、株ドラゴンの価格帯別出来高チャートを切り替えて表示できます。

JPX（日本取引所グループ）公式データに基づき、**東証全上場銘柄（約4,400銘柄）を Consult でインクリメンタル検索**し、大画面チャートを表示できます。コードのみを入力した場合の銘柄名の自動補完機能もあります。

## 主な特徴

- **グリッドレイアウト**  
  ウィンドウ幅に応じて、2列・3列・4列以上に自動で配置を変更します。ピクセル単位の位置指定（`space :align-to`）を使うため、フォント幅や銘柄名の長さに関係なく縦位置が揃います。
- **2種類のチャート形式と代替表示**  
  - **楽天証券**: 日足 / 15分足 / 週足 / 月足（通常テクニカルチャート）
  - **株ドラゴン**: 日足 / 週足 / 月足（価格帯別出来高チャート）  
  `v` キーで切り替えます。株ドラゴン未対応の米国株・ETF や、取得に失敗した場合は、楽天証券のチャートを代替表示します（代替であることを表示に明記）。
- **東証全銘柄の Consult インクリメンタル検索 (`s` キー)**  
  JPX 公式サイトから取得した全上場銘柄（約4,400銘柄）を、33業種の区分つきで絞り込みます。選択した銘柄の大画面チャートを開きます。
- **マルチリスト管理（1〜9スロット）**  
  「よく見る主力銘柄（`meigaralist.txt`）」や「テーマ別・中長期監視（`meigaralist2.txt`）」など、最大9つのリストを管理します。`(` / `)` で存在するリストを順に切り替え、`l` キーで一覧から選択、`M-1`〜`M-9` で番号を指定して切り替えます。
- **大画面詳細モード**  
  サムネイルのクリックまたは `RET` で、大画面チャートを表示します。大画面のまま `n` / `p` キーで前後の銘柄に切り替えられます。
- **外部サイトの表示**  
  `b` キーで Yahoo!ファイナンス、`K` キーで「空売り.net」（日本株のみ）の、その銘柄のページを既定のブラウザで開きます。
- **リストの編集と銘柄名の自動補完 (`e` キー)**  
  `e` キーで、表示中の銘柄リストファイルを編集します。コードのみ記述しておくと、保存時（`C-c C-c`）に東証マスタから正式名称を補完して追記します。
- **不正な画像の破棄、ダーク/ライトテーマ対応**  
  エラー画像や 500B 以下の不正なデータは破棄し、壊れた画像枠を表示しません。ハイライト色はエディタの背景色に合わせて切り替えます。
- **ポータブル設計**  
  必要なスクリプトはすべてパッケージフォルダ内にあります。フォルダごと配置すれば、追加の設定なしで動作します。

## 動作要件

| 項目 | 要件 | 備考 |
| :--- | :--- | :--- |
| **OS** | Windows 10 / 11 | PowerShell / GDI+ リサイズスクリプトを使用 |
| **Emacs** | Emacs 28.1 以上 | PNG / GIF 画像表示対応ビルド推奨 |
| **curl** | Windows 標準搭載 (`curl.exe`) | チャート画像および JPX データの取得 |
| **PowerShell** | Windows 標準搭載 | 株ドラゴン画像の一括リサイズ処理 |
| **Python 3** | Python 3.7 以上 | JPX 東証全銘柄 Excel の解析用（標準ライブラリのみ。pip 不要） |
| **推奨パッケージ** | `consult` | ミニバッファでのインクリメンタル検索。未導入の場合は標準の `completing-read` を使用 |

## インストール・設定方法

### 1. ファイルの配置
本リポジトリを `~/.emacs.d/lisp/stock-charts/` にそのまま配置します。`site-lisp/stock-charts/` に置く場合は、以降の `load-path` の指定を読み替えてください。

```text
~/.emacs.d/
└── lisp/
    └── stock-charts/            ; ★本リポジトリを一式そのまま配置
        ├── stock-charts.el
        ├── update_toushou.py
        ├── resize_dragon.ps1
        ├── README.md
        └── stock-charts/
            ├── meigaralist.txt
            └── meigaralist2.txt
```

### 2. `init.el` への設定記述

```elisp
;; load-path に追加して読み込み
(add-to-list 'load-path (expand-file-name "lisp/stock-charts" user-emacs-directory))
(require 'stock-charts)

;; グローバルキーバインドの例
(global-set-key (kbd "<f9>") #'stock-charts)
(global-set-key (kbd "C-c s s") #'consult-stock-chart-all)
(global-set-key (kbd "C-c s m") #'consult-stock-chart-my)
```

#### `use-package` を使用する場合
```elisp
(use-package stock-charts
  :load-path "lisp/stock-charts"
  :commands (stock-charts
             consult-stock-chart-all
             consult-stock-chart-my)
  :bind
  (("<f9>"     . stock-charts)
   ("C-c s s"  . consult-stock-chart-all)
   ("C-c s m"  . consult-stock-chart-my)))
```

### 3. ポータブル運用と環境変数による保存先の指定
個人 PC 固有の絶対パスを GitHub や設定ファイルに含めたくない場合や、USB メモリ等のポータブル環境で運用する場合は、**起動用バッチファイル等で環境変数を指定**すると、保存先を切り離せます。

| 環境変数 | 説明 | デフォルト値（未設定時） |
| :--- | :--- | :--- |
| `STOCK_CHART_DIR` | 銘柄リスト（`meigaralist*.txt`）の格納フォルダ | パッケージ配置フォルダ内の `stock-charts/`。なければ `~/.emacs.d/stock-charts/` |
| `STOCK_CHART_CACHE_DIR` | チャート画像・TSV等のキャッシュフォルダ | `~/.emacs.d/.cache/stock-charts/` |

**起動バッチ（run-emacs.bat 等）での記述例:**
```bat
:: リストとキャッシュの場所を指定する
set "STOCK_CHART_DIR=%~dp0stock-charts"
set "STOCK_CHART_CACHE_DIR=%~dp0.cache\stock-charts"

start "" "%~dp0emacs\bin\runemacs.exe"
```
※ 環境変数が未設定の場合、リストの保存先は、パッケージ配置フォルダ内の `stock-charts/`、なければ `~/.emacs.d/stock-charts/` の順に決まります。キャッシュは `user-emacs-directory` 配下の `.cache/stock-charts/` です。

### 4. キャッシュの有効期限（TTL）と自動再取得
取得したチャート画像は `.cache/stock-charts/` 配下にローカルキャッシュされます。
- **自動再取得**: 最終取得から **12時間**（デフォルト）が経過した画像は、次回チャートを開いたときや時間軸・銘柄を切り替えた際に自動的に再ダウンロードされます。
- **有効期間の変更**: `(setq my/stock-chart-cache-ttl (* 24 3600))`（24時間）や `(setq my/stock-chart-cache-ttl nil)`（無期限：`g` キーでのみ更新）のように設定可能です。
- **手動更新**: `g` キーで、有効期限に関係なくチャートを再取得します。

## 銘柄リスト (`meigaralist.txt`) の書き方

銘柄リストファイルはシンプルなテキスト形式です。

```text
# よく見る一覧（主力テーマ）   <-- 先頭付近の「# タイトル」行がタブ名に反映

[半導体・製造装置]             <-- [テーマ名] で見出しグループ化
8035 東京エレクトロン           <-- コード [半角スペース] 銘柄名
6857 アドバンテスト
6920 レーザーテック
SMH 米国株ETF(SMH)             <-- 米国株ティッカーにも対応

[金融・メガバンク]
8306 三菱UFJ
8316 三井住友FG
8411 みずほFG
```

- **コメント**: `#` または `//` で始まる行と空行は無視されます。ファイル先頭付近（300バイト以内）の最初の `# タイトル` 行は、タブ名に使われます。
- **銘柄コードの形式**:
  - **日本株・国内ETF**: 4桁数字（例：`7203 トヨタ`）や新コード英字入り（例：`285A キオクシアHD`）
  - **海外銘柄（米国株・海外ETF）**: ティッカーシンボル（例：`NVDA エヌビディア`、`AAPL アップル`、`SMH` 等）を記述すると、楽天証券のチャートを表示できます。
- **証券コードのみ記述時の「銘柄名自動補完」**:
  - 日本株・国内ETFは、銘柄名を省略して **「証券コードのみ」**（例：`7203` や `6758`）記述できます。
  - **ビューア表示時の補完**: 東証全銘柄マスタ（約4,400銘柄）から検索し、ファイル側がコード単体でも「7203 トヨタ自動車」のように正式名称付きで表示します。
  - **保存時の追記**: `e` キーのリスト編集画面で `C-c C-c` を押して保存・終了すると、コードのみの行を検出し、ファイルにも正式銘柄名を追記して保存します。この処理は `my/stock-chart-auto-complete-names-on-save` を `nil` にすると無効になります。
  - **手動での一括補完**: 編集バッファで `C-c C-a` を押すと、銘柄名を一括で補完します。
  - ※ 米国株などの海外銘柄は東証マスタの対象外です。銘柄名が空欄の場合は、ティッカーシンボルが銘柄名として表示されます（日本語名を手動で併記することもできます）。
- **マルチリストのスロット**:
  - `meigaralist.txt`: スロット1（`meigaralist1.txt` があればそちらを優先）
  - `meigaralist2.txt` 〜 `meigaralist9.txt`: スロット2〜9
  - 実在するファイルのみがタブに表示され、順番に切り替えられます。
  - リストが1つもない場合は、サンプルの `meigaralist.txt` が自動作成されます。

## アーキテクチャの解説

### 1. 代替表示
- **株ドラゴン表示時**: 米国株（AAPL, NVDA 等）や一部の ETF、新興銘柄など、株ドラゴンにデータがない銘柄は、楽天証券の通常チャートを表示します。
- **楽天証券表示時**: 楽天証券側でチャートが取得できない場合は、株ドラゴンの価格帯別出来高チャートを表示します。
- 画面上部の銘柄ヘッダーに `〔日足 (楽天代替)〕` や `〔価格帯別・日足 (ドラゴン代替)〕` と表示されるため、どちらのソースの画像かを確認できます。

### 2. 東証全銘柄の TSV 抽出 (`update_toushou.py`)
- JPX公式サイトが提供する最新のExcelファイル（`data_j.xlsx`）をダウンロードし、Pythonの標準ライブラリ（`zipfile` と `xml.etree`）のみで直接展開・解析します。
- pandas、openpyxl などの外部ライブラリを使用せず、約 **0.3秒** で全銘柄の「コード・銘柄名（全角半角の正規化済み）・市場区分・33業種」を TSV に抽出します。

## トラブルシューティング

**Q. 画像が表示されず、文字だけが表示される**  
A. お使いの Emacs が PNG 画像の表示に対応しているか確認してください（`M-: (image-type-available-p 'png)` が `t` を返す必要があります）。Windows 版 Emacs では通常デフォルトでサポートされています。

**Q. 東証全銘柄検索 (`s` キー) を押すとエラーになる**  
A. 初回実行時やキャッシュが存在しない場合、自動的にJPXからデータ取得が試行されます。もしオフライン等で失敗した場合は、インターネット接続を確認のうえ `M-x my/stock-chart-update-toushou-list` を実行してください。

**Q. チャート画像が更新されない**  
A. キャッシュが残っている可能性があります。一覧画面で `g` キーを押すと、キャッシュ画像が破棄されて最新画像が再取得されます。
